# Elo Clinic System

A full-stack web application designed to manage patients and appointments in a clinic environment.

## 🚀 Features
- User authentication (login/register)
- Patient management (CRUD)
- Appointment scheduling
- Dashboard overview

## 🛠 Tech Stack
- JavaScript
- Node.js
- Express
- React (planned)

## 🎯 Purpose
This project simulates a real-world clinic management system and focuses on backend architecture, API design, and scalability.

## ▶️ How to run

```bash
npm install
npm run start
